# X 运营助手

独立开发的 Chrome 扩展，提供 X 首页回复机会评分、双语起草和中文转英文。项目作者 [@yuntan4](https://x.com/yuntan4)。

## 安装

1. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择这个 `x-reply-assistant` 文件夹。文件夹内应直接看到 `manifest.json`。
3. 从 Chrome 工具栏的扩展菜单点击「X 运营助手」，打开设置。
4. 选择 OpenAI 或 DeepSeek，填写对应服务商的 API Key。点击「保存设置」，首次使用 DeepSeek 时按 Chrome 提示授权连接。再点「刷新模型列表」，选中模型后再次保存。可点「测试已保存的模型」检查连接和模型兼容性。

## 试用

### 首页评分

打开 `https://x.com/home`，右侧圆形图标默认点亮。点击关闭，再点开启。当前批次最多 10 条，第 1 名显示 10 分，滚动后按新一批重排。把鼠标移到帖子右上方 Grok 和「更多」之间的分数上，即可查看评分依据。

扩展尝试自动触发已加载作者的 X 悬浮卡片，读取卡片显示的粉丝数和关注资料。未取到的粉丝数暂按 1,000 计算。该功能在本地完成，只读取首页已加载数据和悬浮卡片。

### 帖子详情

1. 打开或刷新一条 X 帖子详情页。点击主帖右上方的「分析并起草」，扩展读取主帖文字和最多 8 条已加载的回复，直接生成结果。
2. 弹窗显示原帖中文、原帖与评论摘要，以及三条接法不同的双语候选或跳过原因。点击候选英文只复制正文，回到 X 手动粘贴发布。只有平台译文、没有加载回复或有媒体未读取时，弹窗会标明限制。
3. 在每张候选卡标题旁的「改写」菜单选择更短、更长或一种语气，卡片内的中英文会一起更新。下方「手动调整」区可选择接法、语气和长度再生成一批候选，结果显示在按钮下方。默认是自动接法、随手回和短回复（140 字符），也可选更短（80 字符）或多说一句（220 字符）。
4. 点空心爱心保存英文和原帖片段，选中显示粉色实心。再点撤销，也可改选同帖的其他候选。也可展开「保存我自己的回复」，填入你最终使用的英文并保存。
5. 在弹窗最下方输入你想回复的中文，点「转换」得到英文，点击译文复制。弹窗底部也有「关闭」按钮。

帖子被截断时，先在 X 展开全文。只读到 X 的译文时，可切回原文后再分析。设置页可以更改时效分段、编辑提示词或恢复默认值。

更新已加载的扩展时，在 `chrome://extensions` 点击这项扩展的「重新加载」，然后刷新 X 帖子页。旧版默认提示词会自动使用新版，自行编辑的提示词会继续保留。

各服务商的 Key 和模型分别保存在当前 Chrome 配置的扩展本地存储中。Key 仅用于向对应的服务商认证。标记的风格示例保存在本地。点击分析、重新生成或改写时，会把当前帖、有限的已加载回复和最近最多 8 条手动保存的英文示例及其标签、原帖片段发送给所选服务商。原帖片段最多 500 字。中文转英文只发送你输入的文字。生成、改写、转换和连接测试使用你自己的 API 额度。

## 本地验证

在项目根目录运行 `node --test tests/reply-assistant.test.mjs`。测试使用模拟请求和页面元素。
